# Codex + Obsidian Brain Setup

This is a personal "second brain" setup using Obsidian and Codex.

Obsidian stores your notes in a local `BRAIN` folder. Codex helps you save, sort, update, and reuse useful information from chats, projects, ideas, tasks, contacts, career work, family notes, hobbies, and more.

## What It Does

- Saves useful information with simple commands like `save to Brain: ...`
- Breaks down long chats and saves only useful facts, tasks, and conclusions
- Stores notes in Obsidian instead of losing them in chat history
- Updates existing notes instead of creating duplicates
- Helps retrieve saved context later in any Codex chat
- Can work with calendar tools if Google Calendar or Outlook Calendar is connected

## What It Is For

Use it to keep track of:

- Career: CV, jobs, interviews, achievements, LinkedIn ideas
- Work: projects, decisions, tasks, context
- Personal life: family, rest, health, home, hobbies
- People: friends, colleagues, recruiters, useful contacts
- Knowledge: ideas, learning, notes, references
- Inbox: raw thoughts that need sorting later

## How To Install

Open [INSTALL_PROMPT_EN.md](INSTALL_PROMPT_EN.md), copy the full prompt, paste it into Codex, and let Codex run the setup.

If Obsidian is not installed, Codex will try to install it through the official Windows package source. If manual action is needed, Codex should stop and explain what to do.

## Main Commands

```text
Save to Brain: ...
Add to Brain: ...
Analyze this chat into Brain
Check Brain for topic: ...
Show me what you will save first
```

See [BRAIN_COMMANDS_EN.md](BRAIN_COMMANDS_EN.md) for the full command list.

## Important

This is not magic and not automatic saving of every message. It works best when you explicitly tell Codex what to save or ask Codex to analyze a chat/project and extract useful information.

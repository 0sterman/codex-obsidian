# Команды Brain

Используй эти команды в Codex после установки.

## Сохранение

```text
Запиши в мозг: ...
Добавь в мозг: ...
Сохрани в мозг: ...
Внеси в мозг: ...
Запиши в Brain: ...
Добавь в Brain: ...
Сохрани в Brain: ...
Внеси в Brain: ...
```

Используй для фактов, задач, идей, контактов, планов, решений, предпочтений и важного контекста.

## Разбор Чатов И Проектов

```text
Разбери этот чат в мозг
Разбери этот чат в Brain
Разнеси этот чат по мозгу
Разнеси этот чат по Brain
Разбери проект в мозг
Разбери проект в Brain
```

Codex должен выбрать полезную информацию и разложить ее по Obsidian.

## Использование Сохраненного Контекста

```text
Проверь мозг по теме: ...
Проверь Brain по теме: ...
Что я знаю про ...?
Используй мой мозг для этого
Используй мой Brain для этого
Ответь с учетом Brain
Подготовь меня, используя Brain
```

Используй, когда Codex должен сначала проверить сохраненные заметки, а потом ответить.

## Inbox

```text
Добавь в Inbox: ...
Добавь в инбокс: ...
Разбери Inbox
Разбери инбокс
```

Inbox нужен для сырых мыслей, которые пока непонятно куда класть.

## Безопасность Перед Сохранением

```text
Сначала покажи, что сохранишь
Сохрани только после подтверждения
Покажи, куда это попадет
Не сохраняй это
```

Используй, если информация чувствительная или ты хочешь сначала проверить, что Codex собирается записать.

## Обзоры И Задачи

```text
Сделай обзор Brain
Сделай обзор мозга
Что важно не забыть?
Покажи незавершенные задачи
Кому я должен написать?
Что у меня по карьере?
Что у меня по семье?
Что у меня по людям?
```

Используй для регулярных обзоров, задач и контактов.

## Календарь

```text
Проверь мозг и найди, что нужно добавить в календарь
Добавь это в календарь
Создай событие из этой заметки
Найди задачи с датами в Brain
```

Работает, если в Codex подключен Google Calendar или Outlook Calendar. Без доступа к календарю Codex может подготовить список событий вручную.

## Новые Разделы

```text
Предложи новую ветку для этого
Создай новый раздел в Brain
Сначала предложи структуру
Перенеси похожие заметки в отдельный раздел
```

Codex должен создавать новые разделы только после подтверждения, особенно если тема начинает повторяться.

# Codex + Obsidian Brain Setup

Set up a personal "second brain" with Obsidian and Codex.

This repository contains ready-to-use prompts and command references that help Codex install Obsidian, create a local `BRAIN` vault, organize notes, and save useful information from chats into structured Markdown files.

---

Настрой личный "второй мозг" на базе Obsidian и Codex.

Этот репозиторий содержит готовые промты и список команд, чтобы Codex мог установить Obsidian, создать локальный vault `BRAIN`, организовать заметки и сохранять полезную информацию из чатов в структурированные Markdown-файлы.

## What This Gives You / Что Это Даёт

- A local Obsidian vault for notes, tasks, ideas, contacts, and decisions.
- Codex commands for saving useful information from chats.
- A structure for career, work, family, people, hobbies, and knowledge.
- A way to reuse saved context later in any Codex chat.
- Rules to avoid duplicate notes and update existing notes when possible.
- Optional calendar usage if Google Calendar or Outlook Calendar is connected.

---

- Локальный Obsidian vault для заметок, задач, идей, контактов и решений.
- Команды Codex для сохранения полезной информации из чатов.
- Структуру для карьеры, работы, семьи, людей, хобби и знаний.
- Возможность потом использовать сохранённый контекст в любом чате Codex.
- Правила, чтобы не плодить дубли, а обновлять существующие заметки.
- Возможность работать с календарём, если подключён Google Calendar или Outlook Calendar.

## Recommended Start / Рекомендуемый Старт

If you use English:

1. Open `README_EN.md`
2. Open `INSTALL_PROMPT_EN.md`
3. Copy the full install prompt into Codex
4. After setup, use commands from `BRAIN_COMMANDS_EN.md`

Если используешь русский:

1. Открой `README_RU.md`
2. Открой `INSTALL_PROMPT_RU.md`
3. Скопируй весь установочный промт в Codex
4. После установки используй команды из `BRAIN_COMMANDS_RU.md`

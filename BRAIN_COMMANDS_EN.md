# Brain Commands

Use these commands in Codex after setup.

## Save Information

```text
Save to Brain: ...
Add to Brain: ...
Store in Brain: ...
Capture in Brain: ...
Write to Brain: ...
```

Use these for facts, tasks, ideas, contacts, plans, decisions, preferences, or important context.

## Analyze Chats And Projects

```text
Analyze this chat into Brain
Save useful parts of this chat to Brain
Sort this chat into Brain
Analyze this project into Brain
Save project context to Brain
```

Codex should extract only useful information and sort it into Obsidian.

## Use Saved Context

```text
Check Brain for topic: ...
What do I know about ...?
Use my Brain for this
Answer using Brain context
Prepare me using Brain
```

Use these when Codex should check saved notes before answering.

## Inbox

```text
Add to Inbox: ...
Sort Inbox
Analyze Inbox
```

Inbox is for raw thoughts that are not ready to be sorted.

## Safety Commands

```text
Show me what you will save first
Save only after confirmation
Show me where this will go
Do not save this
```

Use these when the information is sensitive or you want to review changes first.

## Reviews And Tasks

```text
Make a Brain review
What should I not forget?
Show unfinished tasks
Who should I contact?
What do I have about career?
What do I have about family?
What do I have about people?
```

Use these for weekly reviews, task cleanup, and relationship follow-ups.

## Calendar

```text
Check Brain and find what should be added to calendar
Add this to calendar
Create an event from this note
Find dated tasks in Brain
```

This requires Google Calendar or Outlook Calendar to be connected in Codex. Without calendar access, Codex can still prepare a list of events manually.

## New Sections

```text
Suggest a new branch for this
Create a new Brain section
Suggest the structure first
Move similar notes into a separate section
```

Codex should create new sections only after confirmation, especially when a topic starts repeating.
